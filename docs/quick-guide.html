1. Workflow 30 วินาที (Start in 30 Seconds)

01

เปิดไฟล์ Code Entry

เข้าโฟลเดอร์ extension แล้วเขียน logic ที่ไฟล์ src/extension.ts ในฟังก์ชัน activate()

02

กดปุ่ม F5 เพื่อทดสอบ

VS Code จะเปิดหน้าต่างใหม่ [Extension Development Host] ที่ติดตั้ง extension ของเราไว้พร้อมลองเล่น

03

แพ็ก .vsix ส่งเพื่อน

รัน bun run package เพื่อสร้างไฟล์ .vsix ขนาดเล็ก (2-3 KB) ส่งให้เพื่อนติดตั้งได้เลย

3. กฎเหล็ก 3 ข้อที่ห้ามทำ (3 Deadly Sins)

1. ห้ามลืม Dispose

ทุก Command, Status Bar, Listener ต้องใส่ context.subscriptions.push(...) เสมอ ไม่งั้นเกิด Memory Leak

2. ห้ามรัน Sync หนักๆ

ห้ามใช้ fs.readFileSync ไฟล์ใหญ่หรือลูปหนักๆ เพราะจะทำให้ VS Code ของผู้ใช้ค้างทั้งโปรแกรม

3. ห้ามสแปม Notification

ห้ามเด้ง showInformationMessage ตอนเปิดโปรแกรม ให้ใช้ Status Bar หรือ Output Channel แทน

4. โครงสร้างไฟล์ 4 ไฟล์หลักที่ต้องรู้

ไฟล์ หน้าที่สำคัญ
package.json Manifest: ประกาศคำสั่ง (contributes.commands), เมนู, ปุ่มลัด, และ minimum VS Code version
src/extension.ts Code Entry: ฟังก์ชัน activate(context) (เริ่มทำงาน) และ deactivate() (คืนหน่วยความจำ)
esbuild.js Bundler: รวมไฟล์ TypeScript ทั้งหมดให้เหลือไฟล์เดียวใน dist/extension.js (เปิดติดในเสี้ยววินาที)
.vscodeignore Packaging Filter: กันไม่ให้เอาซอร์สโค้ดดิบและ node_modules ติดเข้าไปในไฟล์ .vsix

5. Top 7 Snippets (ก๊อปปี้ไปวางได้ทันที)

1. ลงทะเบียนคำสั่ง (Register Command)

src/extension.ts
const cmd = vscode.commands.registerCommand('myExt.hello', () => {
  vscode.window.showInformationMessage('สวัสดีจาก Extension!');
});
context.subscriptions.push(cmd);

2. ปุ่มสถานะด้านล่าง (Status Bar Item)

Status Bar
const barItem = vscode.window.createStatusBarItem(vscode.StatusBarAlignment.Right, 100);
barItem.command = 'myExt.hello';
barItem.text = '$(zap) คลิกเพื่อเริ่ม'; // ใช้ Codicons เช่น $(zap), $(gear), $(check)
barItem.tooltip = 'คำอธิบายเมื่อเอาเมาส์ชี้';
barItem.show();
context.subscriptions.push(barItem);

3. กล่องตัวเลือก QuickPick (ถามผู้ใช้แบบเลือกรายการ)

QuickPick
const choice = await vscode.window.showQuickPick(
  [
    { label: 'โหมด A', description: 'ทำงานแบบอัตโนมัติ' },
    { label: 'โหมด B', description: 'ทำงานแบบกำหนดเอง' }
  ],
  { placeHolder: 'เลือกโหมดที่ต้องการใช้งาน...' }
);
if (choice) {
  console.log('ผู้ใช้เลือก:', choice.label);
}

4. กล่องรับข้อความ InputBox (กรอกข้อมูล)

InputBox
const name = await vscode.window.showInputBox({
  title: 'กรอกชื่อโปรเจกต์',
  placeHolder: 'my-project',
  validateInput: (text) => text.trim() ? null : 'กรุณากรอกข้อความ'
});

5. แก้ไขโค้ดใน Editor ปัจจุบัน (Text Editing)

Editor Edit
const editor = vscode.window.activeTextEditor;
if (editor) {
  const selection = editor.selection;
  const text = editor.document.getText(selection);

  await editor.edit((edit) => {
    // แทนที่ข้อความที่คลุมด้วยตัวพิมพ์ใหญ่ (หรือแทรกข้อความถ้าไม่ได้คลุม)
    edit.replace(selection, text ? text.toUpperCase() : '// แทรกข้อความใหม่\n');
  });
}

6. แสดงหลอดความคืบหน้า (Progress Notification)

WithProgress
await vscode.window.withProgress(
  {
    location: vscode.ProgressLocation.Notification,
    title: 'กำลังประมวลผล...',
    cancellable: true
  },
  async (progress, token) => {
    progress.report({ increment: 50, message: 'ครึ่งทางแล้ว' });
    await new Promise(r => setTimeout(r, 1000));
    progress.report({ increment: 50, message: 'เสร็จสิ้น!' });
  }
);

7. เก็บ API Key อย่างปลอดภัยเข้า OS Keychain (Secrets)

SecretStorage
// เก็บ API Key
await context.secrets.store('gemini-key', 'AIzaSy...');

// ดึงมาใช้งาน
const key = await context.secrets.get('gemini-key');

6. คำสั่ง CLI สรุปย่อใน Monorepo นี้

Terminal
# ติดตั้ง dependencies ทั้งหมดในโปรเจกต์
bun install

# สั่ง Compile ทุก Extension ด้วย esbuild
bun run compile

# สั่ง Watch โค้ดของ Extension เฉพาะตัว (แก้งานแล้ว build ทันที)
bun run --cwd extensions/starter-extension watch

# สั่งแพ็กไฟล์ .vsix สำหรับส่งให้เพื่อน
bun run --cwd extensions/starter-extension package

7. วิธีส่งและติดตั้งไฟล์ .vsix ให้เพื่อน

📦 วิธีการสำหรับเพื่อน (ไม่ผ่าน Marketplace)
  1. คุณรันคำสั่ง bun run --cwd extensions/<name> package จะได้ไฟล์ .vsix เช่น starter-extension-0.0.1.vsix
  2. ส่งไฟล์ .vsix นั้นให้เพื่อนทาง Discord, LINE, หรือ Google Drive
  3. ให้เพื่อนเปิด VS Code > กด Cmd+Shift+X (หรือ Ctrl+Shift+X)
  4. คลิกที่ไอคอนจุดสามจุด ... ที่มุมบนขวาของแผง Extensions
  5. เลือก "Install from VSIX..." แล้วเลือกไฟล์ที่ส่งให้
  6. ติดตั้งเสร็จพร้อมใช้งานได้ทันที 100%!
