# vscode-extension

A modern Visual Studio Code extension project powered by [`vscode-extension-creator`](https://github.com/most-too/most-agents-skill).

---

## 🚀 Getting Started

This repository is ready for development. You can:
1. Ask your AI coding agent (Antigravity, Claude Code, Cursor) to scaffold or add features. The agent will automatically detect and use the `vscode-extension-creator` skill.
2. Or develop manually using the recipes from `most-agents-skill`.

### Common Commands
- `npm run compile` - Compile & bundle with esbuild
- `npm run watch` - Watch mode for active development
- `npm test` - Run automated extension tests with `@vscode/test-cli`
- `npm run package` - Production bundling
